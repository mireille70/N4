# KOON — Obsidian Ember Theme

قالب متجر بطاقات رقمية عربي (RTL) للسوق السعودي، مبني بـ React + TypeScript + Vite + Tailwind CSS.

**الهوية البصرية:** واجهة داكنة سينمائية — أسطح سوداء مطفية، إضاءة برتقالية دافئة (`#FF7926`)، خطوط IBM Plex Sans Arabic + Inter، شبكة 8px.
- الألوان والخطوط والزوايا والظلال: `src/theme/themeConfig.ts`
- التدرجات والإضاءة والحركة (`--grad-matte`, `--grad-ember`, `--grad-warm`, `.spotlight`, `.matte`): أعلى `src/styles/index.css`
- أيقونات الفئات بنسخة جرافيت/نحاسي: `node scripts/build-ember-icons.cjs` (الأصلية محفوظة في `public/assets/categories/`)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # فحص الأنواع + بناء الإنتاج في dist/
```

## 1. البنية

| المسار | الغرض |
|---|---|
| `src/theme/themeConfig.ts` | **نظام التصميم كاملاً**: الألوان، الخطوط، الزوايا، حجم الحافة المشطوفة (`notch`)، الظلال، مسافات الأقسام، عرض الحاوية، أعمدة الشبكة، شكل بطاقة المنتج، شكل الأزرار، مستوى الحركة، إعدادات الجوال، الميزات |
| `src/theme/ThemeProvider.tsx` | يحوّل الإعدادات إلى متغيرات CSS و`data-*` على `<html>` — Tailwind يقرأ كل القيم منها |
| `src/content/site.ts` | الهوية، القوائم، التذييل، نصوص صفحات الدخول والحساب |
| `src/content/catalog.ts` | الفئات والمنتجات |
| `src/content/home.ts` | ترتيب أقسام الصفحة الرئيسية ككتل بيانات (`SectionBlock[]`) |
| `src/sections/` | أقسام قابلة لإعادة الاستخدام + `registry.tsx` الذي يربط كل كتلة بمكوّنها (جاهز لمنشئ صفحات) |
| `src/demo/api.ts` | **طبقة العرض التجريبي** — كل استدعاء "خلفي" محاكى هنا فقط |
| `src/store/StoreProvider.tsx` | السلة، المفضلة، الجلسة، الملف الشخصي، الطلبات (محفوظة في `localStorage`) |

### إعادة التخصيص لعلامة أخرى
1. عدّل `themeConfig` (مثلاً `buttons.shape: 'pill'`, `notch: 0`, `motion: 'subtle'`, `productCard.variant: 'framed'`).
2. استبدل المحتوى في `src/content/*` والصور في `public/assets/`.
3. أعد ترتيب/احذف كتل الصفحة الرئيسية في `home.ts`.

## 4. ما هو تجريبي (Simulated)

- لا يوجد خادم: كل ما في `src/demo/api.ts` يحاكي التأخير ويعيد نجاحاً.
- **لا توجد بوابة دفع** ولا تُعرض أي شعارات دفع (مدى، Apple Pay، STC Pay) لأنها غير مفعّلة.
- رمز التحقق: أي 6 أرقام مقبولة. Google/Apple يسجّلان دخول ملف وهمي.
- نقاط الولاء = ريال واحد لكل نقطة من الطلبات التجريبية (قاعدة عرض فقط).
- البيانات محفوظة في متصفح المستخدم فقط. كل شاشة تجريبية تعرض ملاحظة واضحة بذلك.

## 5. ملاحظات على المحتوى (للمراجعة)

**تصحيحات على أخطاء واضحة في المرجع:**
- صفحة إنشاء الحساب كان عنوانها وزرها "تسجيل الدخول" → "إنشاء حساب".
- حقل "الاسم الكامل" كان نصه التوضيحي "أدخل بريدك الإلكتروني" → "أدخل اسمك الكامل".
- بطاقة Bath & Body Works كانت تحمل اسم "Hunger Station" → "Bath & Body Works".
- حقوق النشر كانت "ASUS 2024" → تُقرأ من `site.brand.name` (KOON).

**محفوظ كما هو في المرجع، ويحتاج استبدالاً من صاحب المتجر:**
- نص التذييل والوصف (لوريم إيبسوم عربي).
- مجموعة الخيارات الثانية في المنتج مكررة العنوان "المنطقة" وفيها "عالمي" مرتين.
- التقييم 4.8 (528,275,209) — يمكن إخفاؤه بـ `features.showRatings: false`.
- صفحة التحقق تقول "بريدك الإلكتروني" بينما الاستعادة تتم بالهاتف.

**إضافات غير موجودة في المرجع:**
- الأسعار: فقط فري فاير (5.00) من المرجع، وبقية الأسعار **قيم تجريبية**.
- أسماء عربية للمنتجات (مثل "فالورانت")؛ المرجع يعرض الشعارات الإنجليزية فقط.
- نصوص واجهة ضرورية: حالات فارغة، رسائل التحقق، ملخص الطلب، شارة "جديد".
- رمز Xbox مرسوم يدوياً (غير متوفر في simple-icons). بقية شعارات المنصات من simple-icons.
- علم الدولة الافتراضي السعودية (+966) بدلاً من العلم المصري الظاهر في المرجع.

## 6. الجودة

- واجهة عربية RTL أصلية، أرقام لاتينية، "ر.س" بعد المبلغ.
- تم الفحص على 1440 / 1024 / 768 / 375 بكسل دون تمرير أفقي.
- فحص axe-core (WCAG 2 A/AA + best practices) على 11 مساراً: 0 مخالفات.
- 35 اختباراً وظيفياً شاملاً (المسارات، معرف اللاعب، السلة، الطلب، الدخول بالرمز، الحفظ، المفضلة، البحث، الخروج): كلها ناجحة.
- تقسيم الشيفرة حسب المسار، صور WebP بتحميل كسول، احترام `prefers-reduced-motion`.
